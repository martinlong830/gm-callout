## Getting started (everyone)

### Install & open

1. **Mobile:** Install Shiflow from the App Store or Google Play.
2. **Web:** Open [https://shiflow.app/](https://shiflow.app/) in a browser.
3. **Time clock tablet (web only):** On the login screen use **Time clock tablet sign in** — choose Location **8th Ave**, enter the device name and password, then **Open time clock**. Staff punch with a PIN on that tablet (not in the employee app).

Managers often use the website for schedule templates, shift times, location management, and Excel exports. Day-to-day schedule, team, availability, and timecards also work in the mobile app.

### Sign in

Same flow on web and mobile:

1. Tap **Log in**
2. Enter company **Access code** → **Continue**
3. Enter **Name** + **Password** → **Sign in**

Password fields show dots as you type (on Android those dots stay visible after a recent display fix). There is no show/hide toggle.

### Forgot password / reset

1. On the sign-in screen choose **Forgot password?**
2. Enter your **Name** → **Send reset link**
3. Open the email sent to your account **recovery email**
4. Choose a new password (**Update password** on web; same reset screen in the app)

Set recovery email under **Account** so resets work. If nothing arrives, ask your manager or email **[support@shiflow.app](mailto:support@shiflow.app)**.

## For employees

**Mobile tabs:** Home · Schedule · Availability · Actions · Messages  
(Same ideas on the web employee portal.)

### Home — today & upcoming

Home shows **Today**, **Upcoming** shifts, and recent requests — only for **published** weeks. If a week is missing, it is probably not published yet; ask your manager.

### Schedule

- Browse weeks with the week controls.
- Location chips appear if you are set to **Both**; 8th-only staff see only **8th Ave**.
- Unpublished weeks show **Not published yet** — “Your manager will notify you when it is ready.”

### Availability

1. Mark when you can work on the grid.
2. Use **Check all** if helpful.
3. Tap **Submit** (mobile) or **Submit availability** (web).


| Status   | Meaning                                         |
| -------- | ----------------------------------------------- |
| Draft    | Not submitted yet                               |
| Pending  | Waiting for your manager to approve             |
| Approved | Manager accepted your availability              |
| Declined | Manager declined — update and resubmit if asked |


### Actions

- **Time Off** — vacation or sick leave
- **Shift Swap** — offer or accept a swap (manager still approves)
- **Callout** — you cannot cover a scheduled shift; add notes for your manager

Managers review these under **Actions** (**Approve** / **Decline**).

### Messages

Chat with managers and coworkers — search threads and **Send**.

### Clocking in

Employees do **not** punch from the employee app. Use the store **Time Clock** tablet with your **4-digit PIN** (set by your manager on **Team**).

### Notifications

When a manager taps **Publish / Notify**, the week becomes visible and Shiflow tries to send a push notification.

You must open the Shiflow app on a real phone and **allow notifications** for pushes to register. During onboarding, some phones may not get a push yet — also check **Home** / **Schedule** in the app, and expect managers to tell the team in person when a week goes live.

## For managers

**Mobile tabs:** Schedule · Team · Availability · Actions · Messages · Timecards  

**Web also has:** **Templates**, **Shift Times**, **Manage Locations**, **Undo**, and **Download timecards** / **Full report (Excel)**.

### Team / staffing

Search and filter by restaurant and role. Use **Add employee** for new hires. In the editor set:


| Field                 | 8th Ave guidance                                                                  |
| --------------------- | --------------------------------------------------------------------------------- |
| **Location**          | **8th Ave** for store-only staff; **Both** + **Primary location** for multi-store |
| **Hourly rate ($)**   | Used in timecards / payroll math                                                  |
| **Time clock PIN**    | 4-digit PIN for the tablet (Random PIN / Save PIN on mobile)                      |
| Portal account fields | Sign-in name / recovery email so they can log in (web editor)                     |


Register the store tablet with Location **8th Ave** so punches attribute to this store.

### Building & editing the schedule

1. Open **Schedule** and switch the location chip to **8th Ave**.
2. Browse rolling weeks (past + current + near future).
3. Assign people by tapping cells / people. On web: open a slot → **Edit Staffing** → **Save Schedule**; use Coverage / Call outreach as needed.
4. Empty future weeks can seed from the current week pattern.
5. **Web only:** **Templates** (Apply / Save / Delete), **Shift Times**, **Manage Locations**, **Undo**.

### Publish & Notify

For the **selected week** (not a past week):

- **Publish / Notify** — makes the week visible to employees and attempts a push.
- After publish, the button becomes **Notify again**.
- **Past weeks are disabled** — you cannot publish or notify a week that has already passed.

If publish succeeds but no push tokens are registered yet, employees can still see the week in-app. Tell staff to open Shiflow on their phone, allow notifications, and check **Schedule**. Do not rely on push alone during onboarding.

### Availability (approve / decline)

1. Open **Availability**.
2. Select an employee and week.
3. Review **Pending**, edit the grid, use **Check all** if needed.
4. **Save** / **Approve** / **Decline**.

### Actions (requests)

Filter **Time Off** / **Shift Swap** / **Callouts** and Pending / Closed / All. **Approve** or **Decline**. Coverage outreach history shows awaiting / covered status.

### Timecards

1. Set **Location** to **8th Ave**.
2. Pick the pay week.
3. Roster shows Scheduled, Regular, **OT**, VL/SL, SoH, dishwasher tips, Coverage, Total.
4. Open a person → a shift to edit punches, breaks, VL/SL, tips.


| Concept             | How it works                                                                                                                                                                         |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Tip take-home %** | Editable for the selected store. **8th Ave default is 80%** (9th Ave is 95%). Net tip = gross × %. Select 8th or 9th to edit (control is disabled until a single store is selected). |
| **OT**              | First 40 hours regular **per restaurant** in the pay week; overtime at 1.5×                                                                                                          |
| **Export**          | **Web only:** **Download timecards** — Summary / Shifts / **Full report (Excel)**. Mobile has no Excel/CSV download.                                                                 |


Punches come from the Time Clock tablet. Managers edit punches on timecard shift screens.

## Onboarding checklist — 8th Ave

### Day 1 — new manager

- [ ] Install Shiflow on your phone and open [https://shiflow.app/](https://shiflow.app/) on a computer
- [ ] Sign in with company **Access code** → **Name** → **Password**; save recovery email in **Account**
- [ ] On **Schedule**, switch location chip to **8th Ave**
- [ ] Open **Team** — confirm each 8th Ave person has **Location** set to **8th Ave** (or **Both** + **Primary**)
- [ ] Set or confirm each staff **Time clock PIN**; register the store tablet as Location **8th Ave**
- [ ] Build the upcoming week on 8th Ave, then tap **Publish / Notify** (not a past week)
- [ ] Tell staff to open the app, allow notifications, and check **Schedule** — also announce in person
- [ ] On **Timecards**, select Location **8th Ave**; confirm **Tip take-home %** (default **80%**)
- [ ] Review **Availability** **Pending** list; **Approve** or **Decline**

### Day 1 — new employee

- [ ] Install Shiflow or open [https://shiflow.app/](https://shiflow.app/)
- [ ] **Log in** → **Access code** → **Name** → **Password** (from your manager)
- [ ] Open **Account** — confirm sign-in name and recovery email for **Forgot password?**
- [ ] Allow notifications when prompted
- [ ] Check **Home** for **Today** / **Upcoming** shifts (published weeks only)
- [ ] Open **Schedule** — confirm you see **8th Ave** (or Both if you work both stores)
- [ ] Submit **Availability** for the weeks your manager asked for
- [ ] Learn your 4-digit **Time clock PIN** — clock in on the store tablet, not in the employee app

### Common gotchas


| Symptom                         | Likely cause                                                 | Fix                                                                     |
| ------------------------------- | ------------------------------------------------------------ | ----------------------------------------------------------------------- |
| Cannot sign in                  | Wrong Access code, Name, or password                         | Confirm with manager; use **Forgot password?** if recovery email is set |
| Wrong store on Schedule         | Location set to 9th Ave or Both unexpectedly                 | Manager: **Team** → set **Location** to **8th Ave**                     |
| Week says **Not published yet** | Manager has not published that week                          | Manager: **Schedule** → select week → **Publish / Notify**              |
| No push after publish           | Phone never opened app / denied notifications / no token yet | Staff open app + allow notifications; also announce in person           |
| Cannot **Publish / Notify**     | Selected week is in the past                                 | Move to current or future week                                          |
| Tip % grayed out                | Location filter not a single store                           | Select **8th Ave** on Timecards                                         |
| Employee cannot punch in app    | Expected — no employee punch UI                              | Use **Time Clock** tablet with PIN; device Location = **8th Ave**       |
